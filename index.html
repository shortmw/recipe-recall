랜덤 퀴즈

등록한 음료 종류와 사이즈의 레시피를 기준으로 출제해요.

원하는 문제 수만큼 랜덤으로 풀어요. 빈 항목과 예시 레시피는 제외해요. 재료·첫 행동 문제는 다른 레시피에서 오답 보기를 만들 수 있을 때, 순서 문제는 제조 순서가 두 줄 이상일 때 출제돼요. 횟수는 사이즈가 등록된 음료만 출제해요.

내 레시피 노트

사이즈·음료 종류별로 한 장씩 등록하면 더 정확하게 연습할 수 있어요.

퀴즈에서 ‘다시 연습할래요’를 누른 음료를 모아 볼 수 있어요. ‘기억했어요’를 누르면 목록에서 빠져요.

사이즈로 보기

다시 연습 표시만 해제하며, 레시피와 연습 횟수는 보관돼요. 전체 해제는 분류에 관계없이 모든 다시 연습 음료에 적용돼요.

설정

백업과 오프라인 사용을 여기에서 관리할 수 있어요.

오프라인 사용 준비 중…
새 버전 적용 방법

새 버전 팝업에서 ‘지금 적용’을 누르세요. 팝업을 닫았다면 이 설정 화면의 ‘새 버전 적용’을 누르면 돼요.

인터넷에 연결한 뒤 앱을 다시 열면 업데이트를 확인해요. 작성 중인 내용은 먼저 저장하고 진행 중인 연습은 마쳐 주세요.

휴대폰 홈 화면에 설치하는 방법

아이폰: Safari에서 이 사이트를 열고 공유 버튼 → ‘홈 화면에 추가’를 선택하세요.

갤럭시: Chrome에서 이 사이트를 열고 메뉴(⋮) → ‘홈 화면에 추가’ 또는 ‘앱 설치’를 선택하세요.

추가한 아이콘으로 한 번 실행한 뒤 ‘오프라인 사용 준비 완료’를 확인하면 인터넷 없이도 사용할 수 있어요.

오프라인 사용이란?

인터넷이 연결된 상태에서 앱을 한 번 열어 오프라인 준비를 마치면, 인터넷이 없어도 저장된 레시피를 보고 퀴즈를 연습할 수 있어요.

새 레시피와 연습 기록은 이 기기에 저장돼요. 파일 백업으로 저장해 두면 다른 기기에서도 불러올 수 있어요.

파일 백업

PC · iPad · iPhone · 갤럭시(Android) 백업 호환

‘백업 파일 저장’ 또는 ‘백업 공유’로 만든 JSON 파일은 PC, 아이패드, 아이폰, 갤럭시(Android)에서 서로 호환돼요. 한 기기에서 저장한 파일을 파일 앱·카카오톡 등으로 옮긴 뒤 다른 기기의 ‘백업 불러오기’에서 선택하세요.

레시피와 연습 기록은 함께 저장되며, 기존 백업 파일 형식도 계속 불러올 수 있어요. 기기를 바꾸거나 브라우저 데이터를 지우기 전에는 백업 파일을 먼저 보관해 주세요.

횟수는 선택 사항이에요. 시럽·첨가물 종류와 단위는 재료 칸에 적어 주세요.

새 버전이 준비됐어요

‘지금 적용’을 누르면 새 버전으로 바뀌고 화면이 새로고침돼요.

저장된 레시피와 연습 기록은 유지돼요. 저장하지 않은 입력과 진행 중인 연습은 초기화되니 먼저 저장하거나 마쳐 주세요.

나중에 적용하려면 ‘나중에’를 누른 뒤, 준비됐을 때 톱니바퀴 설정 → ‘새 버전 적용’을 선택하세요.
