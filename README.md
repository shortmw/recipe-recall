# 한 잔씩 — GitHub Pages 배포용

이 폴더의 파일 전체를 저장소 최상단에 업로드하세요.
Settings → Pages → Deploy from a branch → main → /(root) → Save.

## 데이터 옮기기
기존 사이트 설정에서 백업 파일 저장 → 새 사이트 설정에서 백업 불러오기.
암호를 지정했다면 동일한 암호를 입력하세요. 주소가 다르면 브라우저 저장소도 다르므로 자동 이전되지 않습니다.

## 지원 기능
레시피 등록/수정/삭제, 분류/검색, 암기 연습, 랜덤 퀴즈, 복습 표시, 파일 백업/복원, 암호화 백업, 오프라인 설치, 업데이트 안내.
파일 공유는 브라우저가 지원하는 경우 제공되며, 그 외에는 파일 저장을 사용합니다.

## 업데이트
수정 파일을 업로드할 때 sw.js의 캐시 버전 v1을 v2 등으로 올리세요.
오프라인 사용은 온라인으로 최초 접속해 준비 완료 후 가능합니다.
구글드라이브 연결 기능은 포함하지 않습니다.
